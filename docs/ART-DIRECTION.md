# 美术方向（Lead 视觉干预记录）

本文件是本轮视觉改稿的方向与验收约束。任何后续修改（人或模型）不得单点回退这些设定。

## 1. 方向

一句话：**暴风夜里的一艘猎船，用一盏油灯照着一只会发光的深海巨兽。**

三条硬规则：

1. **明度三层**：天空（亮）→ 雾与海面反光（中）→ 船体与巨兽主体（暗）。
   主体永远比背景暗一档，靠冷色边缘光与水面反光把轮廓"抠"出来。
2. **一个暖一个冷**：全场冷调（风暴蓝 `#22384c` / 水体 `#0b1c2a`），
   甲板只允许一盏暖油灯（`#ffb167`）。暖色只出现在船与船员身上，不许过水。
3. **HUD 是航海仪表**：黄铜细边（`#c9a063`）+ 极暗玻璃面板 + 顶部 1px 高光。
   禁止纯灰描边、禁止圆角气泡、禁止无背板的浮空长句。

- `test_scene` 66 / `test_combat` 67 / `test_aim_feedback` 21 / `test_balance` 40 / `test_limb_hits` 56 / `test_legal_encounter` 全绿。

## 4. 下一步（按性价比排序）

1. **模型比例与剪影**：现在头部偏圆、触手排布放射对称，读起来像玩具。
   需要一次真正的比例重做（压扁下颌、拉长触手、做一组非对称主势）。
2. **贴图**：鳞片尺寸全画面一致，缺少远近变化；需要 2–3 级不同密度的鳞片与湿滑高光。
3. **动画**：呼吸/涌动幅度偏小，巨兽"不动如山"，缺少压迫感。
4. **甲板细节**：木板、绳索近景仍然糊，需要更强的法线细节。

## 6. 建模改稿（第二轮）

目标：把"宽扁圆头 + 放射对称触手 + 珍珠流苏"的玩具感压下去。

已改（均在 `scripts/sea_monster.gd`）：

| 部位 | 改动 |
| --- | --- |
| 躯干 | `ContinuousNeckAndTorso` 中段加粗（2.65→3.0 / 2.55→3.12），`DorsalTrapezius` 肩肌加宽，头部相对变小（`_head.scale` 1.25,1.15,1.0 → 1.12,1.04,1.1） |
| 眼睛 | 眼窝 0.46×0.19 → 0.62×0.30，眼球/虹膜/竖瞳同步放大；新增 `BrowRidgeOverhang` 眉脊悬挑，眶上盾片抬高并前倾 |
| 嘴 | 静止张口 `_jaw.rotation.x` 0.035 → 0.15；`DeepMouthGap` 加深加宽；新增 `PharyngealVoid` 咽腔暗块；獠牙 2 根 0.77 → 4 根 0.95/0.78，上排每隔 3 颗抽掉 1 颗，破掉"拉链" |
| 触须 | 每侧 10 根细珍珠须 → 6 根粗短不等长须，珍珠只留每侧 1 颗。原来那排是"流苏珠帘"，整个脸部最廉价的一处 |
| 剪影 | 左舷（`side<0`）触手整体下压外扩，左上层触手额外后仰抬升 → 打破左右镜像 |

**重要约束（踩过一次）**：`test_aim_feedback` 里有一条"相机看得见背面核心、但炮口射线先撞到触手"的公平性反例，它打的是**右舷**（ship 在 x=+85）。任何把右舷触手抬高/外移的改动都会让这条用例失败（我试过 1.06/1.11 的整体放缩，直接挂）。
所以：**非对称只能做左舷**。右舷的原始姿态是这条公平性用例的参数，不要动。

验收：6 套测试全绿（66/67/21/40/56/legal）。

仍然做不到的：这是纯程序化拼装（椭球 + 管 + 盾片），没有拓扑、没有 UV、没有雕刻。要真正跨一个档次，需要外部建模软件做一张带法线的模型替换掉 `sea_monster.gd` 的生成逻辑 —— 那是另一个量级的工作。


## 7. 第三轮：巨兽重建 + 界面重做（本轮）

上一节结尾写的是「要真正跨档需要外部建模」。本轮没有外部资产，但把**生成方式本身**换掉了：
从「椭球 + 管 + 盾片拼装」改成**连续曲面**（顶点网格 + 真实 UV + 解析法线），
所以 §6 里「没有拓扑、没有 UV」的限制不再成立。

### 7.1 几何（`scripts/sea_monster.gd`，1595 行，整文件替换）

| 系统 | 做法 |
| --- | --- |
| 网格基元 | `_grid_mesh()`：任意 rows×cols 点阵 → 中心差分法线（按行心自动朝外）+ UV + 索引；`_superellipse()` 给肌肉横截面（指数 2.3–2.35，不是正圆） |
| 躯干 | `ArmoredTorso`：9 个关键截面放样，背线在 y≈4.5 向后隆起、颈部再折回 → 弓背潜行姿态；龙骨、腹侧压平、肩胛起伏都在截面函数里 |
| 头颅 | `AbyssalSkull`：沿 +Z 的掠食者楔形放样（颞部最宽 → 吻端收窄），腹面压平 0.62 形成上颚面；`_head.scale` 1.12,1.04,1.1 → **1.26,1.16,1.20**（头部成为最大体块） |
| 下颌 | `HookedMandible`：独立铰接放样，静止张口 `_jaw_rest` 0.15 → **0.38**，吻端下垂 |
| 牙 | 上下各两排交错：上 17+12、下 14+10；6 颗獠牙 1.55–2.05、半径 0.15，**越出下颌线**咬合 |
| 眼 | 黑眼球 + 程序化竖瞳 `EYE_SHADER`（虹膜纤维 / 角膜高光 / 极暗巩膜），眼眶骨环 + 眉脊悬挑 + 副眼三枚 |
| 诱光 | 颌角垂落的两枚 `AnglerLure`（发光器 + OmniLight）留在吻下，**不进入额头弱点视线** |
| 肢体 | 姿态沿用旧版（右舷是公平性参数，见 §6）；渲染改椭圆截面 + 平行移动标架（不拧麻花）+ 腹面吸盘凹陷 + 背缘锯齿刃鳍 `LimbBladeFin` + 末端钩爪 `LimbHookClaw` |
| 非对称 | 左舷最上层巨肢自后上方越过颅顶；左角折断并生骨茬，右角完整带三叉 |

### 7.2 材质（新 `SKIN_SHADER` / `EYE_SHADER`）

- **鳞片**：3D Voronoi（27 邻域）在**静止空间**求细胞穹顶与鳞缝，经 `instance uniform rest_position_*` 绑定，肢体摆动时纹理不滑动；两层密度（主鳞 + 细鳞）避免单一尺度。
- **皮下散射**：`BACKLIGHT` 冷红，鳍膜/鳃裂逆光透血色 —— 「活体」的关键一笔。
- **湿润**：鳞顶 ROUGHNESS 0.19、鳞缝吸水变哑；SPECULAR 随表面类型变化。
- **生物光**：鳞缝渗出青色 + 稀疏发光孔（细胞哈希阈值），随时间脉动。
- **凹凸**：dFdx/dFdy 表面梯度，保留旧版 NaN/退化保护（`slope_sq < 1e5`）。
- 旧版依赖的 `assets/monster/abyss-scales.png` **不再被采样**（文件保留，全仓无引用）。

### 7.3 轮廓光（新增，最关键的一步）

巨兽 MeshInstance 统一 `layers = 1 | 4`，并自带三盏只作用于第 3 层的 `DirectionalLight3D`
（`SilhouetteRim` 主轮廓 / `EdgeKicker` 背缘 / `MawFill` 口腔补光）。
灯是巨兽子节点，随转向保持同一明暗关系 —— 在风暴天幕前剪影始终被「抠」出来，而甲板油灯仍照常打亮它。

### 7.4 界面（`scripts/battle_hud.gd`，1111 行，整文件替换）

设计语言：**黄铜航海仪表**。三条规则：

1. **字号只有五档**：34（船体数字）/ 30（巨兽名）/ 22（武器）/ 17（提示）/ 14 / 11（微标签）。正文最小 14，不再有满屏 10–11px 低对比灰字。
2. **信息分三层**：巨兽横幅（分段血条 + 幽灵残影）→ 准星/威胁/单行提示 → 船体、武器、雷达。中景留给画面。
3. **一色一义**：BRASS 奖励/弱点、TEAL 玩家资源、BLOOD 危险、VIOLET 敌方读条。面板一律 1px 黄铜细边 + 顶部 1px 高光，无圆角。

具体：`Meter` 自绘条（分段刻度/幽灵残影/顶部高光）取代 ProgressBar；右上三个图标钮；雷达缩到 200px 重画刻度环；
简报页改电影黑边 + 左栏排版（eyebrow / 60px 标题 / 发丝线 / 键帽 chip / 三行战术 / 主按钮）；
结算页新增 `hud.set_result()` 数据条（历战 / 船体 / 抢修 / 残留敌血）；暂停与结算共用同一套按钮排布。
`tools/shot.gd` 新增 `--shot-overlay=briefing|paused|victory|defeat`，可离屏验收任意弹层。
`scripts/encounter_settings.gd` 同步换色与字体（原先蓝灰边框与主界面不是一套语言）。

## 8. 第四轮：把「原型手感」换成「商业手感」

这一轮不动模型与玩法判定，只补**每一帧都在花钱的地方**：时间、次级运动、粒子密度、镜头语言、音乐、UI 动效。

### 8.1 打击感（`scripts/sea_battle.gd`）

| 项 | 实现 |
| --- | --- |
| 命中冻结 | `_impact(duration, freeze_scale)`：破核 0.090s@0.14、重炮 0.070s@0.20、普通命中 0.040s@0.36、弹反 0.170s@0.16、破防 0.130s@0.20、阶段 0.220s@0.28、终局 0.300s@0.12。冻结只压 `_process` 喂给 `simulate()` 的 delta，表现层按真实时间走 —— 所以冻结期间镜头、粒子、UI 仍在动，这才是「顿」而不是「卡」 |
| 覆盖规则 | 只有冲击强度 `duration*(1-scale)` 更大的事件才能覆盖正在进行的冻结，避免连击把时间轴压死 |
| 镜头推力 | `_push` 脉冲：向目标推 0.9 m、抬 0.22 m、收 2.4° FOV，指数回落 |
| 音频挤压 | 新增 `Combat` 总线（混响 0.13 wet + 低通 20500Hz）；冻结时低通压到 760Hz、音量 −7dB，随 `_duck` 回落 |

**测试安全**：冻结只作用在 `_process` 上，测试直接调用 `simulate(step)`，判定与 30/60Hz 公平性完全不受影响。

### 8.2 镜头语言（`_update_camera`）

固定机位 → 五态小状态机（默认 / 逼近 / 蓄力压低 / 释放后拉+微滚 / 击杀抬升），参数经 `lerpf(delta*3.4)` 平滑：
逼近时距离 11→10.1、高度 6.4→5.9、注视点 10.2→10.9；蓄力再压 1.15 m 并抬头 1.35，读起来像「它正俯身看你」；
胜利时抬升 4.8 m 并后拉 3.2 m，把沉没的巨兽留给画面。

### 8.3 画面密度（`atmosphere.gd` / `arena.gd`）

- 雨 288 → **1100** 段；泡沫 180 → 320 且单块尺寸 1.7×3.1 → 6.4×7.6（**原尺寸在 70 m 外只有 2px，等于没画**）；水雾 22 → 44 且 6.5×2.2 → 17×6；飞沫 96 → 240 且 0.026 → 0.10 m。
- 新增 `BossWaterlineSurge`：220 块白沫沿吃水线做外扩行波，证明巨兽真的「泡在水里」。
- 新增 `LightningFlash`：`lightning/thunder` 招式期间冷光打亮全域（能量 7.5，环境光同步抬升）。
- 新增 `DeckLampCone`：甲板油灯的 SpotLight3D，在体积雾里形成可见光锥（暖色只落在甲板，不违反 §1 的「暖色不过水」）。

### 8.4 巨兽次级运动（`sea_monster.gd` + 皮肤 shader）

没有骨骼，就在**顶点着色器**里做沿肢体静止轴传播的行波：
`sway_axis`（轴 + 长度）与 `sway_motion`（相位 / 振幅 / 频率 / 偏置）是 **instance uniform**，由 `_bind_limb_sway()` 在网格合并之后逐肢写入；
振幅 0 的部件（躯干、头）完全不受影响。六条巨肢与前肢各自相位不同，所以是「一节推着一节」，不是整体摇摆。

**振幅刻意限制在 0.10 局部单位 = 0.3 m 世界尺度**，落在命中胶囊的容差内（胶囊本身另有 2.5%+padding），不改变「看得见就打得到」。

### 8.5 程序化配乐（`battle_audio.gd`）

三条 stem：`drone_loop`（A1 低音弦堆叠 + 风噪，16s）/ `pulse_loop`（64 BPM 心跳，7.5s）/ `tension_loop`（小二度音簇 + 颤音，16s，两端淡到 0 以便无缝）。
按阶段与强度交叉淡入：一阶段只有低音床 + 心跳，二阶段加入张力弦，残血时心跳推高。
配乐按 11025 Hz 生成（低频，够用），加载停顿从 1.64s 压到 **0.82s**。

### 8.6 UI 动效（`battle_hud.gd`）

船体数字滚动 + 掉血回弹（缩放 + 偏红）、血条 `smooth` 缓动填充带高光边、换武器时卡片弹一下并亮起、
提示条从下方 8px 滑入、弱点窗口呼吸、战斗开始时整层 0→1 淡入 + 准星回弹、按钮 hover 呼吸。

### 8.7 验收（本轮实测）

- 6 套测试全绿（21 / 56 / 40 / 67 / 66 / legal），在以上全部改动落地后跑。
- 900 帧实机冒烟：无 SCRIPT ERROR；`generation_ms≈815`。
- 离屏：`work/z1-battle.png`（实机）、`work/z2-hero.png`（次级运动后的近景）。

### 8.8 未验证 / 仍缺

- 程序化配乐有天花板：它能给情绪，但给不了主题动机。
