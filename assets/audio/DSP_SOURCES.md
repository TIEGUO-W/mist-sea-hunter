# 试战声音来源与制作说明

本轮运行音色全部由 `scripts/battle_audio.gd` 的确定性 DSP 参数与算法原创合成；没有采样外部录音、音乐、人声或商用音效包，也没有使用音频生成服务。它们是程序合成声音，不能视为专业实地录音或已获真人试听认可。

## 本地素材核查

仓库 `assets/audio/fubo_guling` 包含四个运行鼓点 WAV 和一个源 MP3。`docs/assets/fubo-guling-generated-assets.md` 将其记录为 `TAIKO DRUM 001.wav`（Freesound sandyrb，演奏 Tyson Goodyear）的 CC BY 4.0 衍生，并列有来源链接、署名与哈希。本轮没有再次联网核验许可页；这些素材属于太鼓小游戏，不能覆盖当前试战的木铁机械、湿重水击与技能提示，因此**没有复用或打包这些第三方鼓点**。

## 合成音色

- 连弩：高通木扣瞬态、非谐木体模态、下滑弦响与延后的机械碰撞。
- 重炮：短高频点火、低频变调冲击、过滤噪声与暗色尾响。
- 鱼叉：非整数倍铁件模态、发射瞬态及缆绳滑动噪声。
- 命中：低频湿重结构和短水花；弱点额外增加克制的高频碎裂层。
- 陨石/闪电：不同的起势、火石坠海低频/水汽，以及叉电瞬态/低雷余响。
- 扑击/爪扫：低吼、气流与水体压力；防御、弹反、破防有不同瞬态与衰减。
- 环境：原创过滤噪声海风/浪涌、木船非谐微响；立体声循环交叉淡化，不使用录音循环。

22.05 kHz / 16-bit PCM，事件为单声道以便3D定位，两个环境层为立体声。单音离线峰值限制为0.72（约−2.85 dBFS），环境0.56；运行时再留增益余量，并把并发事件的保守峰值之和约束在0.78以内，再加低电平环境，避免只依赖单音不削波。3D距离增益上限为0 dB。环境层低于关键预警。

`original_dsp/*.wav` 是以上源码离线烘焙的23个原创缓存，并非外部采样。运行 setup 优先通过正常导入资源或 `res://` 虚拟文件系统读取缓存，不把资源路径转为PCK外的磁盘地址；缓存缺失时才回退到同一DSP生成。每帧不生成WAV。更改合成参数后需重新离线烘焙对应缓存，并重做峰值和试听验证。

运行最多16个复用3D事件播放器与2个环境循环；独立音高RNG不消耗战斗/相机随机数。事件按优先级抢占，低优先级射击不挤掉已占满的高优先级预警。暂停保留播放位置，未进入音频线程的首帧3D播放请求会被暂停并在恢复时单次继续，恢复不新建/叠加循环。静音使用精确线性增益0。重开 `reset()` 只清播放状态，保留音色缓存和原有18个播放器；离场 `stop_all()` 为幂等永久释放，显式 stop、stream=null、queue_free，调用方仍按规范等待0.15秒真实时间清理音频线程。

## 对比试听

`dsp-comparison.wav` 由隔离验证脚本离线导出：先播放旧版简易正弦/低通噪声示意（连弩、重炮、鱼叉），随后播放本轮相同三武器及水击、闪电、弹反，末尾展示低电平环境。具体时间轴见 `dsp-comparison-timeline.json`。此对比只用于可复核听辨，不代表已经通过真人听感验收。

## 锁点提示补充

用户反馈后增加target_lock：0.24秒的原创短促下滑铁音与高通瞬态，在陨石落点停止跟踪时单次播放，与长蓄力及坠落声分开。仍由同一DSP离线烘焙，不含外部采样；23个音色共用原16事件/2环境播放器和优先级规则，静音时由HUD与海面边线传达同一锁点。
